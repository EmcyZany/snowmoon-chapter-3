# Snowmoon Chapter 3 — "A Choice of Roles"

An AI-generated video adaptation of Chapter 3 of *Snowmoon*, the 32-chapter science-fiction novel by Vitalik Buterin. Made as an entry for the [Bring Snowmoon to Life](https://poidh.xyz/mainnet/bounty/34) bounty.

Gladias walks through Meldan to a quiet booth in Greater Plum Harbor, where a stranger named Delwart makes him an offer: don't become a Sentinel — become a Keeper, and vote to delete every rubric. *Freedom. Actual freedom.* The film ends where the chapter ends: a follower in the crowd, a watch chime, and a call left unanswered.

## What's in this repo

- `scenes/` — one folder per scene: 28 scenes and 7 inserts. Each folder has a `SCENE.md` with the generation prompt, the dialogue, and edit-placement notes. Upload the final video take as `clip.mp4` in its folder.
- `prompts/` — every generation prompt used, the shared visual-continuity block, and the cast/environment reference prompts.
- `dialogue/` — the full dialogue script in edit order.
- `docs/` — the CapCut assembly sheet, voice guide, workflow notes, and the tools/models used.
- `assets/` — character and environment reference images.

## Audio

There are no separate audio masters in this repo. All dialogue and ambient audio used in the final edit was extracted from the video files themselves.

## How it was made

One locked reference image per character and environment; each scene generated as a ~10-second clip and assembled in CapCut. Faces, costumes, and voices were kept consistent across every take — see `docs/voice-guide.md` and `docs/workflow.md` for the rules that held it together.
